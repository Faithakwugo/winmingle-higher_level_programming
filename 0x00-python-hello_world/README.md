# 0x00. Python - Hello, world
These programs illustrate the use of python interpreters,
how to print strings and variables using
print and write function. Uses of strings, indexing and
slicing and bytecode compilation in python. Official python
code style was also implemented in this project.

## Files
-2-print.py - prints a sentence
-101-compile - compiles a Python file to '.pyc'
-102-magic-calculation.py - reproduces given bytecode
